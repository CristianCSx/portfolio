# 🚀 Personal Portfolio with Astro

Welcome to my personal portfolio built with modern frontend ecosystem technologies. This project is designed to be fast, clean, and fully responsive.

---

## ✨ Tech Stack

This project is built with:

- ⚡ **Astro** – A modern framework for ultra-fast static websites

- 🎨 **Tailwind CSS** – Utility-first CSS framework for fast and consistent styling

- 📝 **@tailwindcss/typography** – Optimized typography styles for rich text content

- 🧩 **Flowbite** – Reusable UI components built on top of Tailwind CSS

---

## 🧞 Commands

All commands are run from the root of the project, in a terminal:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `pnpm install`            | Installs dependencies                            |
| `pnpm dev`               | Starts local development server at `localhost:4321` |
| `pnpm build`             | Builds your production site to `./dist/`         |
| `pnpm preview`           | Previews your build locally before deploying     |
| `pnpm astro ...`         | Run CLI commands like `astro add`, `astro check` |
| `pnpm astro -- --help`   | Get help using the Astro CLI                     |
