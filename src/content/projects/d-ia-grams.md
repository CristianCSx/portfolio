d-ia-grams es un proyecto desarrollado como trabajo de fin de grado el cual tiene como objetivo apoyar, facilitar y ayudar en el aprendizaje del lenguaje UML.

Cuenta con un chat que permite realizar preguntas sobre el lenguaje UML que serán respondidas por un modelo de inteligencia artificial de OpenAI que tiene integrado.

Las principales tecnologías usadas para desarrollar el proyecto han sido **Python** como lenguaje de programación, **Django** como framework para realizar la estructura MVC que permite funcionar a la aplicación, **PostgreSQL** como base de datos para almacenar la información y **PlantUML** como herramienta que permite la generación de imágenes de diagramas de clase mediante diagramas en lenguaje Mermaid.
