Ruidos, atascos, contaminación foncalizada y otros inconvenientes son la consecuencia de la falta de un software que permita a los conductores poder ver en tiempo real la disponibildad de plazas libres en los aparcamientos de una cuidad.

**Smartlot** ha sido desarrollado con una arquitectura de microservicios y las tecnologías de React para el frontend y Java Spring para el backend. Como medida de seguridad se ha implementado un orquestador de peticiones y un gateway.

Gracias a este proyecto se pudo obtener y afianzar conocimientos en el **desarrollo de aplicaciones web**, **ciberseguridad** y **trabajo de equipo**.
