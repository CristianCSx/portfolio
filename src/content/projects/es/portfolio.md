Este portfolio se ha desarrollado con el fin de poder aprender a desarrollar páginas web estáticas usando el framework de **Astro** y aplicar estilos de forma fácil gracias a la librería de **Tailwind CSS**.

El aprendizaje ha sido de forma autónoma consultado principalmente vídeos y las documentaciones correspondientes de cada tecnología.

Se ha intentado profundizar conocimientos haciendo uso de las `contentCollections` para realizar el apartado de los proyectos, cuyo contenido está definido en archivos Markdown.

En un futuro se planea desplegar el proyecto en el hosting **Vercel** y vincular un dominio propio comprado a través de **Cloudflare** para su acceso.
