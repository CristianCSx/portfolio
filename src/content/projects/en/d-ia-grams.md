D-ia-grams is a project developed as a final-year thesis aimed at supporting, facilitating, and assisting in the learning of the UML language.

It features a chat function that allows users to ask questions about the UML language, which are answered by an integrated OpenAI artificial intelligence model.

The main technologies used to develop the project were **Python** as the programming language, **Django** as the framework for implementing the MVC structure that powers the application, **PostgreSQL** as the database for storing information, and **PlantUML** as a tool for generating class diagram images using Mermaid-formatted diagrams.
