This portfolio was developed following the courses by the educator and software developer **Midudev**, with the goal of learning how to build static websites and apply styles quickly and easily using technologies such as the Astro framework and the Tailwind CSS library.

I have sought to deepen my knowledge by using **`contentCollections`** to create the projects section, whose content is defined in Markdown files.

In the future, I plan to deploy the project on **Vercel** hosting and link a custom domain purchased through **Cloudflare** for access.
