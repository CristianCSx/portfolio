Noise, traffic jams, localized pollution, and other inconveniences are the result of a lack of software that allows drivers to see, in real time, the availability of open parking spaces in a city.

**Smartlot** was developed using a microservices architecture and React for the frontend and Java Spring for the backend. A request orchestrator and a gateway were implemented as security measures.

Thanks to this project, we were able to gain and strengthen our knowledge in **web application development**, **cybersecurity**, and **teamwork**.
